# Teoría de Juegos · Infografía interactiva

Página interactiva para exponer el tema **Teoría de Juegos** en la asignatura de Investigación de Operaciones. Recorre en diez capítulos la síntesis teórica: desde el equilibrio de Nash hasta los juegos cuánticos, con simulaciones y un Dilema del Prisionero jugable.

## Empezar

**Ver en línea:** <https://sebasramirezm.github.io/teoria-de-juegos/>

O abre `index.html` en Chrome, Edge o Firefox. No requiere instalación.

- [Guía de ejecución](GUIA_EJECUCION.md): cómo abrir, preparar y manejar la página.
- [Guía de exposición](GUIA_EXPOSICION.md): qué decir y cómo usar cada interacción.
- [Síntesis teórica](teor_a_de_juegos_s_ntesis_te_rica.md): el documento fuente del contenido.
